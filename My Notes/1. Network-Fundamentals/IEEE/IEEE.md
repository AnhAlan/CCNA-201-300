- Layer 2 / Switching
    + 802.1D → STP (chống loop)
    + 802.1Q → VLAN tagging
    + 802.1w → RSTP (STP nhanh hơn)
    + 802.1s → MSTP (nhiều STP instance)

- Ethernet
    + 802.3 → Ethernet (chuẩn LAN có dây)
    + Có nhiều biến thể:
    + 802.3u → Fast Ethernet (100 Mbps)
    + 802.3ab → Gigabit Ethernet (cáp đồng)
    + 802.3z → Gigabit Ethernet (cáp quang)

- Tổng thế
    + 802.1 → Switching (VLAN, STP)
    + 802.3 → Ethernet (wired LAN)
    + 802.11 → Wireless (WiFi)
